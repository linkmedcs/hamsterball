# 对象字段与调用约定初表

仅适用于锁定 SHA-256 的 EXE。偏移均为字节。静态证据、继承的隔离执行证据与完整游戏实测必须分开。本轮未重新执行先前 Unicorn 探针。

## 运动对象

| 偏移／调用 | 观察 | 置信范围 |
| --- | --- | --- |
| `+0x00` | 构造写入虚表 `0x4f5d40` | 静态＋原先隔离探针确认；虚表槽含义未完全确认 |
| `+0x10` | 构造保存 EAX 上下文值 | 汇编可见；实际游戏上下文对象类型未知 |
| `+0xc60` | 初始化为 3，求解器用于迭代限制 | 原先探针读值＋本轮求解器代码核对；关卡覆盖未知 |
| `+0xc64` | 方向缩放函数保存 scalar | 原先 100 组输入输出验证 |
| `+0xc68/+0xc6c/+0xc70` | 初始化约为 `0.555/1/1000` | 已读初始化值；不能命名为最终摩擦／重力／速度 |
| `+0xc78` | 初始化为 25，参与缩放计算 | 半径候选；真实游戏覆盖及单位未知 |
| `+0xc8c..+0xc94` | 三分量方向，初始化 `(0,-1,0)` | 原先探针＋本轮汇编／伪代码核对 |
| `+0xc98..+0xca0` | 三分量方向乘 scalar 的存储结果 | 原先 100 组输入输出验证 |
| `0x4627d0` | 对象由 ESI 传入，上下文在 EAX，调用初始化 | 不应照抄反编译器猜测的标准 C++ 签名 |
| `0x4014b0` | 对象在 EAX，一个 scalar 由栈传入 | 原先隔离执行验证；存在寄存器传参约定 |
| `0x463200` | 对象 ECX；栈参数为输出、位置、位移、半径向量、上下文、命中标志指针 | 原先空场景探针支持；接触路径未执行验证 |
| `0x463200` 内虚调用 | 通过碰撞对象虚表 `+8` 与 `+0xc` 调用 | 本轮反编译与反汇编可查看；对象 ABI 与返回结构待恢复 |
